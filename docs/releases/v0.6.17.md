# Release v0.6.17

Date: 2026-10-23

## Summary
- Updated the Go toolchain requirement to Go 1.26.10 to resolve GO-2026-6809, a standard-library `crypto/x509` vulnerability reported by `govulncheck`.

## Install and Update
New install:
```
# Linux/macOS
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc

# Windows
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

Update:

```
lrc self-update
```

## Changes
- Bumped the `go` directive in `go.mod` and `blastradius/go.mod` from 1.26.9 to 1.26.10.
- Cleared the `govulncheck` failure caused by GO-2026-6809 in `crypto/x509` (found in Go 1.26.9, fixed in Go 1.26.10).
- Release binaries are now built with Go 1.26.10.
