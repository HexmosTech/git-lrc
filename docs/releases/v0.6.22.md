## Summary
- Local reviews now show **cross-repo impact**: when a changed function calls
  a route exposed by one of your related repositories, the review names that
  repository and route, without cloning or indexing it on your machine.
- Blast Radius **Math Mode now explains the score you actually got**. It walks
  through the saturating `sqrt(sum of symbols)` roll-up, the file-level
  signals, any cross-repo bonus applied afterwards, and the scaling step.
- Four new options make the review pipeline easier to automate:
  `--cross-repo`, `--cross-repo-timeout`, `--repo-url`, and
  `--save-blast-radius`.

## Changes
- **Cross-repo blast radius in local reviews.** `lrc review` sends the
  outbound HTTP calls it finds in the local code graph to LiveReview, matches
  them against the routes declared by your organization's related
  repositories, and folds the results into the blast-radius report. Related
  repositories are never cloned or indexed locally. The match request is
  best-effort and bounded, so a slow or unreachable server never blocks or
  fails the review.
- **Related repos are visible, not just scored.** The panel shows each
  related repository as a blue underlined link with its friendly name, a
  visible route chip, and a version-match badge, and the Sunburst and Flame
  graphs draw cross-repo branches in blue. Two-hop chains are shown with
  their hops when the server reports them.
- **Math Mode matches the scorer.** The derivation now includes the sqrt
  combine, the "add this hunk's file-level signals" step, an explicit
  post-scoring adjustment when a cross-repo bonus was added after the
  roll-up, and the scale step. Older reports keep their original linear
  arithmetic, so historical reviews still explain themselves correctly.
- **New flags:**
  - `--cross-repo` (default on; disable with `--cross-repo=false`) controls
    cross-repo enrichment.
  - `--cross-repo-timeout` (default `45s`) caps how long the review waits
    for the match request.
  - `--repo-url` overrides the git remote URL used to resolve the review to a
    connected repository.
  - `--save-blast-radius` writes the final report, including enrichment, to
    a JSON file for CI and agent runs.
- **Release safety.** The release process now requires the local security
  scanners to pass before a version is tagged.

## Breaking Changes
- None. Cross-repo enrichment is on by default, but it is best-effort: with
  no related repositories configured, or no server reachable, reviews behave
  exactly as before.

## Verification
- `lrc --version` reports `v0.6.22`.
- `lrc review --help` lists `--cross-repo`, `--cross-repo-timeout`,
  `--repo-url`, and `--save-blast-radius`.
- Run `lrc review --skip` in a repository with related repos configured and
  open a hunk's Blast Radius panel: the related repo, route, and Math Mode
  steps should appear.

## Known Issues
- Cross-repo results depend on the related repositories configured in
  LiveReview. When none are configured, the panel shows no related-repo
  cards.
- A review started while the server is unreachable keeps its baseline
  (local-only) blast radius and does not retry the cross-repo match.
