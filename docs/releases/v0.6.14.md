# Release v0.6.14

Date: 2026-10-01

## Summary
- Fix an intermittent CI failure in the `claude-installer-local` job caused by a cleanup race in the installer test harness.

## Install and Update
New install:
```
# Linux/macOS
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc

# Windows
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

Update:

```
lrc self-update
```

## Changes
- `tests/installer-test-lib.sh`: `cleanup_installer_test_env` now retries `rm -rf` on the test's temp root up to 5 times (with a short sleep between attempts) instead of running it once. The Claude Code CLI can still be writing `.claude.json` into the test's temp `$HOME` right after the test's foreground commands return, which occasionally raced the cleanup and failed it with `Directory not empty`, taking down the `claude-installer-local` CI job (and any local `make test-install-local`/`test-plugin-bootstrap`/`test-plugin-hooks`/`test-loop-prevention` run sharing this harness) even though all the actual test assertions had passed.
