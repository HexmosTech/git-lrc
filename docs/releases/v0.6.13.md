# Release v0.6.13

Date: 2026-10-01

## Summary
- Fix blast-radius/review-priority scoring so hunks touching several low-impact symbols no longer outrank hunks touching one high-impact symbol with real callers.

## Install and Update
New install:
```
# Linux/macOS
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc

# Windows
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

Update:

```
lrc self-update
```

## Changes
- `blastradius/blastradius.go`: `ScoreHunks` now combines a hunk's per-symbol `BlastRadiusRaw`/`ReviewPriorityRaw` contributions with `math.Sqrt` of their sum instead of a flat linear sum, matching the saturating blend already used for the type text-reference/method score. This stops a hunk that happens to touch many low-risk symbols (e.g. several small, mutually-calling helpers newly added in one file) from outscoring a hunk touching a single symbol with a genuine external caller chain.
