# Release v0.6.16

Date: 2026-10-23

## Summary
- Fixed a CSRF vulnerability in the local review server that let a malicious web page trigger state-changing review actions such as skip, commit, vouch, abort, and handoff.

## Install and Update
New install:
```
# Linux/macOS
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc

# Windows
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

Update:

```
lrc self-update
```

## Changes
- State-changing requests to the local review server are now rejected when the browser-supplied `Origin` or `Referer` does not match the server host.
- Requests with a body must use `Content-Type: application/json` (or a `+json` media type), so simple cross-site form posts using `text/plain`, `application/x-www-form-urlencoded`, or `multipart/form-data` cannot reach the decision handlers.
- Requests with no `Origin` and no `Referer` continue to work for non-browser clients, and the existing review-session check still applies.
- Added regression tests covering cross-origin JSON, cross-origin text/plain, cross-origin Referer, `null` Origin, bodyless requests, and same-origin requests.
