# Release v0.6.15

Date: 2026-10-05

## Summary
- The blast-radius review UI now blends each finding's severity (critical/warning/info) into the hunk risk score, so a critical security bug outranks a trivial typo even in a lower-blast-radius change.

## Install and Update
New install:
```
# Linux/macOS
curl -L https://hexmos.com/ipm-install | bash && ipm i HexmosTech/git-lrc

# Windows
iwr https://hexmos.com/ipm-install-ps | iex; ipm i HexmosTech/git-lrc
```

Update:

```
lrc self-update
```

## Changes
- Blast-radius hunks are now ordered by a score that blends the structural blast-radius/review-priority score (90%) with the most severe LLM finding on the hunk (10%; critical=100, warning=25, info=5).
- The "why this score" breakdown panel now includes a **Finding Severity** dimension alongside Blast Radius and Review Priority, plus a severity chip (Critical/Warning/Info) with color coding.
- Math Mode now walks through the severity step and ends on the blended final score, so the headline number and the sort order stay consistent.
- The severity sort only applies where the local review UI already has finding-severity data; webhook- and web-UI-triggered reviews without it are unaffected.
