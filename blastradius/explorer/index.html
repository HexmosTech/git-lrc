How is this scored?

Every hunk gets two independent scores, each normalized 0-100 within this diff (100 = the riskiest/hardest hunk in this diff, not a universal scale), plus a Combined score that blends them (default 60% blast radius / 40% review priority) into one ranking number. All three are shown - Combined to sort by, the other two to see why.

blast radius

How broadly the change could ripple outward - who/what breaks, including outside the codebase. Built from: transitive caller count (up to 3 hops, decayed, square-root-compressed so one "hub" symbol can't swallow the scale); being an HTTP handler (real route method+path, via the graph's Route nodes) or being reached from one within the same call walk; a repo-wide hotspot/architectural layer check (is this symbol a known top-fan-in node, or in the tool's "core"/"api" layer, independent of this diff); implementing (or defining) a widely-reused interface - a plugin-style extensibility point where every implementer/consumer matters; callers spread across many packages; and lightweight keyword-on-path heuristics for auth, persistence (writes data), config, build system, and schema files.

review priority

How much attention this specific hunk deserves from a reviewer. Primarily: a near-duplicate implementation exists elsewhere in the codebase (did you remember to fix it in both places? - weighted higher when the duplicate lives in a different file) and missing test coverage. Supplemented by lighter code-metric signals (cyclomatic/cognitive complexity, loop nesting, fan-out) - these are secondary, not the primary driver, since intrinsic code complexity alone doesn't predict customer impact.

Each hunk's file also gets a small file co-change coupling bonus (folded into blast radius) from git history: files that have historically changed together even without a code reference between them. Separately, hygiene signals - formatting-only, comments-only, generated code, logging-only, test-only-file, dead-code removal (verified against real repo-wide caller counts, not just this diff) - multiply the final Combined score down (shown as a "×0.xx" badge) rather than adding a point, since a trivial change to a critical function should still rank low. Impacted packages (shown per-symbol/hunk, ranked diff-wide below) are the packages/directories a symbol's blast radius reaches.
